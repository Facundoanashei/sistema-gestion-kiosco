# Sistema de Gestión para Kioscos

Sistema desarrollado para administrar productos, ventas y stock de un kiosco, aplicando conceptos de programación, bases de datos y desarrollo web.

## Funcionalidades principales

- Registro y gestión de productos
- Control de stock
- Registro de ventas
- Consulta de información almacenada
- Interfaz web simple para uso del sistema

## Tecnologías utilizadas

- Python
- HTML
- SQL / Base de datos
- Git y GitHub

## Objetivo del proyecto

Aplicar conocimientos de desarrollo backend, frontend básico, persistencia de datos y análisis de requerimientos en una solución práctica orientada a la gestión comercial.

## Estado del proyecto

Proyecto académico/personal en desarrollo.
